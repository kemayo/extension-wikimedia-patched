WikimediaPatched

What this extension does

It runs code from an unmerged Gerrit change inside a wiki page, with your account signed in. That code can do anything you can do. Only add a patch after you read it.

It cannot apply PHP, hooks, schema changes or new module registrations. Those need a real deploy. Use patchdemo for those.

Production wikis

Development wikis work without a prompt. A production wiki needs two things: permission for the domain, below, and a confirmation for that one site. Use Allow on this site in the popup for the confirmation. It lasts until you close the browser.

    Debug mode

    Debug mode lets the extension compare the code a wiki runs against the code the patch was written for. Without it a patch still applies, but the popup cannot tell you when the base does not match.

    Stuck cookie

    The extension turns on ResourceLoader debug mode so it can compare the live code against the patch base. Debug mode makes a wiki much slower. If a wiki stays slow after you turn the extension off, clear the cookie here.
